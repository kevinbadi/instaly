# Instaly - Instagram DM Automation SaaS

A multi-tenant SaaS platform that allows users to automate Instagram DMs at scale. Users sign up, connect their Instagram account, provide post URLs to scrape leads from, and the system automatically sends personalized DMs on their behalf.

## 🚀 Features

- **User Authentication** - Secure signup/login with Supabase Auth (Email + Google OAuth)
- **Instagram Connection** - Connect accounts via Steel.dev secure browser
- **Lead Scraping** - Scrape users from any Instagram post via PhantomBuster
- **AI-Powered Messages** - Personalized DMs generated by Claude AI
- **Campaign Management** - Create, pause, and monitor automation campaigns
- **Analytics Dashboard** - Track DMs sent, response rates, and more
- **Subscription Billing** - Stripe integration with tiered pricing

## 🌐 Deployment

### Frontend (Vercel)

1. Push to GitHub
2. Connect repo to Vercel
3. Add all environment variables from `.env.local`
4. Deploy!

### Worker (Mac Mini)

Run as a background service using launchd:

```bash
# Create launch daemon
cat > ~/Library/LaunchAgents/com.instaly.worker.plist << 'EOF'
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN">
<plist version="1.0">
<dict>
    <key>Label</key>
    <string>com.instaly.worker</string>
    <key>ProgramArguments</key>
    <array>
        <string>/path/to/venv/bin/python</string>
        <string>/path/to/worker/worker.py</string>
    </array>
    <key>RunAtLoad</key>
    <true/>
    <key>KeepAlive</key>
    <true/>
    <key>WorkingDirectory</key>
    <string>/path/to/worker</string>
</dict>
</plist>
EOF

# Load the service
launchctl load ~/Library/LaunchAgents/com.instaly.worker.plist
```

## 🔒 Security Features

- **Row Level Security (RLS)** - Each user can only access their own data
- **Supabase Auth** - Secure authentication with email verification
- **Session Isolation** - Instagram sessions are encrypted and scoped per user
- **Webhook Verification** - Stripe webhooks are signature-verified

## ⚠️ Important Notes

### Rate Limiting
- Instagram has strict rate limits
- Default: 200 DMs/day per account
- Worker adds 30-60 second delays between DMs

### Session Management
- Sessions typically last 90+ days
- If session expires, user must reconnect via Steel.dev
- System automatically marks accounts as "needs_reauth"

### Compliance
- Ensure compliance with Instagram's Terms of Service
- Users are responsible for their usage
